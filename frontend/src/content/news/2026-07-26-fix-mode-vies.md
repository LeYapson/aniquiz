Deux corrections sur le mode vies suite aux premiers retours :

- **Mauvaise réponse** — le champ de saisie se désactive immédiatement après une mauvaise tentative. Fini de pouvoir rejouer indéfiniment dans le même round.
- **Pas de réponse** — ne pas répondre avant la fin du round coûte maintenant une vie. Le mode vies punit aussi le silence, pas seulement les erreurs.
